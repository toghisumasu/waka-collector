## 1. 背景：連歌の付合と距離の概念

連歌には古来より「疎句（そく）」と「密句（みっく）」という概念がある。

- **疎句（遠い）：** 前句とbuiが大きく異なる付句。世界が大きく転換する
- **密句（近い）：** 前句とbuiが近い付句。世界が継承・深化される

名人連歌師は、前句からどれだけ遠ざかり、どれだけ近づくかを体で計算して付句を詠んでいた。この感覚を定量化し、計算機で扱えるようにしたのが距離評価関数の出発点である。

## 2. 距離の定義

### 2.1 語彙非重複率（Phase0で検証・入場条件として確定）

MeCab形態素解析で前句・付句の内容語（名詞・動詞・形容詞・副詞）を抽出し、Jaccard距離を計算する。

```
語彙非重複率 = 1 - |前句語彙 ∩ 付句語彙| / |前句語彙 ∪ 付句語彙|
```

**水無瀬三吟の測定結果：** 平均0.997、中央値1.000、標準偏差0.017

この結果から、語彙非重複率は「連歌の入場条件（最低限の常識）」であり、変化律を測る物差しにはならないと確定した。連歌の名人の付句は、ほぼ例外なく前句と異なる語彙を使う。

### 2.2 bui Jaccard距離（Phase1で実装・基準値確立）

部立（bui）の集合間の距離を計算する。式目上の句材分類（植物・動物・降物・聳物・光物・水辺・居所・時分・恋・述懐・旅・釈教・神祇・人倫・名所）を使用。

```ruby
def bui_jaccard_distance(set_a, set_b)
  return 1.0 if set_a.empty? && set_b.empty?
  intersection = (set_a & set_b).size
  union        = (set_a | set_b).size
  1.0 - intersection.to_f / union
end
# 0.0 = 完全一致（同じbuiの連続）
# 1.0 = 完全非重複（buiが全く異なる）
```

**水無瀬三吟の測定結果：** 平均0.795、中央値1.000、標準偏差0.323

## 3. 変化律：速度より加速度が重要

bui距離の値そのもの（速度）より、連続するペア間の変化量（加速度）が重要である。

```
加速度[n] = bui距離[n] - bui距離[n-1]
```

水無瀬三吟の付合は「高原（距離1.0連続）→急落（加速度-1.0）→即時回復（+1.0）」というジェットコースター的なリズムで構成されている。長い溜めが最大の落下を生む。

| 33 | 二折表中 | 述懐→述懐 | 第一谷 |
| 71 | 三折裏 | 恋→恋 | **最深谷への突入（6句溜め後）** |
| 76 | 三折裏 | 植物・居所→居所・植物 | クライマックス後の静止 |
| 82 | 名残折表 | 恋→恋 | 恋の反響 |

| 99 | 名残折裏末 | 人倫→人倫 | 挙句への最終収束 |

## 5. 実装構想：測定器から制御器へ

### 5.1 役割の転換

**当初の設計（事後評価）：**
```
生成 → 距離計測 → 評価
```

**確定した設計（事前制御）：**
```
距離計測 → 目標と比較 → Rubyが指示 → 生成
```

距離評価関数が測定器から制御器になる。骨法はRuby・即興はメンタムさんという設計原則の自然な拡張である。

### 5.2 折別目標距離による制御

```ruby
FOLD_TARGET_DISTANCE = {
  "初折表"  => 0.750,
  "初折裏"  => 0.792,
  "二折表"  => 0.833,
  "二折裏"  => 0.887,
  "三折表"  => 0.875,
  "三折裏"  => 0.714,
  "名残折表" => 0.750,
  "名残折裏" => 0.679
}

# Rubyによる事前制御のイメージ
target = FOLD_TARGET_DISTANCE[current_fold]
current_distance = bui_jaccard_distance(maeku_bui, candidate_bui)

if current_distance < target - TOLERANCE
  instruction = "前句と異なる世界（#{suggest_distant_bui(maeku_bui)}）で詠め"
elsif current_distance > target + TOLERANCE
  instruction = "前句の余韻を引き継ぎながら詠め"
end
```

### 5.3 2段階生成方式

メンタムさんのbui列を埋めるための2段階方式：

**Stage 1：** 前句を見て、次句で使いたいbuiを宣言させる
```
「この前句（bui=植物・時分）に対して、次に詠む付句の部立を選べ。JSON形式で返せ。」
→ {"selected_bui": ["水辺", "人倫"]}
```

**Stage 2：** 宣言されたbuiと折別目標距離を確認してから詠ませる
```
「選んだbui（水辺・人倫）で付句を詠め。現在の折（三折表）では疎句が望ましい。」
```

## 6. 連歌スタイルパラメータ体系

### 6.1 スタイルの定義

連歌の距離律はスタイルとして着せ替えできる設計とする。ShikimokuCheckerの`ruleset`着せ替えと同じ構造で、骨法（式目）と詩法（距離律）が同じ原理で管理される。

| スタイル名 | 作品 | 捌き/作者 | 年代 | 位置づけ |
|---|---|---|---|---|
| `minase` | 水無瀬三吟百韻 | 宗祇・肖柏・宗長 | 1488 | **室町連歌スタイル**（座の連歌・合作） |
| `yugama`（将来） | 湯山独吟等 | 宗祇 | 室町期 | **宗祇スタイル**（独吟・一人の構想） |
| `atago`（将来） | 愛宕百韻 | 紹巴（捌き） | 1582 | **紹巴スタイル**（政治的文脈を除いた純連歌として） |
| `edo`（将来） | 幕府連歌 | 江戸期捌き | 江戸期 | **江戸幕府連歌スタイル**（固定化・厳格化） |

### 6.2 スタイル間の歴史的な意味

- 水無瀬三吟（1488）→ 愛宕百韻（1582）の約100年で、室町連歌の距離律がどう変化したかが計測で見えてくる
- 宗祇の独吟（湯山等）は一人の構想が純粋に現れる。メンタムさんは独吟システムであるため、宗祇スタイルとの比較が最も本質的
- `minase`（室町連歌）はメンタムさんが最初に学ぶ基準値。`yugama`（宗祇独吟）を計測した段階で、独吟として本来の比較対象が揃う

## 7. 将来展望：スタイル比較と三点測量

### 7.1 スタイル計測の順序

1. **水無瀬三吟（完了）：** `minase`スタイルの基準値確立済み
2. **湯山独吟等：** DBに収録済み。計測により`yugama`スタイルを確立
3. **愛宕百韻：** 政治的文脈を除いた距離律として`atago`スタイルを確立
4. **メンタムさんの百韻：** 各スタイルとの波形比較によりプロンプト評価

### 7.2 独吟固有の問題

メンタムさんは三人の座ではなく一人で詠む。宗祇の独吟スタイル（yugama）が最も直接的な参照対象になる理由はここにある。室町連歌（minase）は三名の総体として生まれた律であり、独吟には宗祇が一人で担った律が必要である。

### 7.3 三点測量

同一前句に対してClaude・Gemini・メンタムさんが付句を生成し、三者のbui距離分布を比較する。メンタムさんの分布が各スタイルの範囲内に収まるかを評価指標として確立する。
