## 設計原則（変更禁止）

1. **枯れてから足す** — 実害が観測されてから対処
2. **骨法はRuby・即興はメンタムさん** — 式目判定はRuby、付句生成はLLM
3. **ShikimokuCheckerは純粋関数** — 外部状態・DB参照を持ち込まない
4. **正解データは水無瀬三吟** — テストの期待値は水無瀬三吟に準拠
5. **1タスク=1コミット**
6. **差分提示→承認→実装** の順序を厳守
7. **RC-COMMIT・RC-PUSH必須** — git log --oneline -1 とgit push完了を受入基準末尾に必ず追加
