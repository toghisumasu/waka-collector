## 依頼書の判断基準に照らして

| 判断基準 | 該当 |
|---|---|
| 3割合がほぼ均等（各33%前後）→ 構造的問題 | 全プールは該当気味（37/35/28）だが、これは旧世代を含むため |
| ピタリが過半数 → 現状維持 | 現行構成でも 46% で僅かに届かず |
| 字余り／字足らずに偏り → 原因分析 | **現行構成で該当**。字足らず(32%) が 字余り(22%) の約1.5倍 |

### 所見

1. **全プール 37/35/28 をそのまま「構造的問題」と読むのは不正確。** 旧世代（字余り優勢）が母数の8割超を占めるため。
2. **現行構成の実態は「ピタリ46% / 字足らず偏り」。** must_continue 強化系（ZATSU_SEED_BIAS / shift_window / directive_lines、其の八十五 Phase1）以降、字余りは抑制済みで、残る課題は字足らず方向。
3. 字足らず偏りの心当たり: Step1.5 音数調整の下限補正（<25音で遠景追加）や Step3 モーラ調整が、目標ちょうどではなく目標未満で収束しているケース。docs/phase0_deflock_report.md（25〜49音デッドゾーン）・Step3 モーラ調整 Phase0 と地続きの可能性。

### 推奨する次アクション

- **改善依頼書を起票するなら「字足らず解消」に絞る**（字余りは現行構成で既に沈静化）。
- renga_verses（インタラクティブ本番）の過不足率は、本番VPS（163.44.114.31:8081）で同じ集計を回さないと取れない。ただし機能は2日前稼働開始で成立句が僅少と見られ、統計的判断には時期尚早。数週間運用後に再集計を推奨。
