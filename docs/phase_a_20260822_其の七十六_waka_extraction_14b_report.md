## 1. 結論（要約）

**モデルを14bへ切替したことで一部の指標は改善したが、根本課題（Step3形式整形の低成功率）は解消していない。8.5時間規模のPhase B実施判断を変えるほどの改善ではない。**

| 指標 | qwen3:8b（7/30報告） | qwen3:14b（本報告） | 変化 |
|---|---:|---:|---|
| create成立 | 5/10句 | **7/10句** | 改善 |
| forced_zatsu逃げ込み | 5/10句（うちmora_ng 2件） | 3/10句（うちmora_ng 2件） | 改善 |
| ng率 | 84.0%（42/50） | 80.0%（32/40） | 微改善 |
| A層（ShikimokuChecker）到達率 | 17.1%（6/35） | **29.0%（9/31）** | 改善（約1.7倍） |
| 1句あたり平均所要時間 | 307.7秒 | 293.4秒 | 微改善 |
| 1句あたり平均Ollama呼出回数 | 96.9回 | 87.4回 | 微改善 |
| 1句あたり最大Ollama呼出回数 | 176回（v1） | 176回（v5） | 変化なし |
| 180秒タイムアウト超過 | 5回 | **0回** | 改善 |
| Step3（形式整形）の呼出構成比 | 67.4%（653/969） | 70.6%（617/874） | 変化なし（悪化方向） |

- **A層到達率とcreate成立率の改善は本物。** ng率・レイテンシの微改善よりも、正規経路（Step1〜Step3〜ShikimokuChecker）を最後まで通過できた回数が明確に増えている。
- **一方でStep3の支配的な重さは変わらない。** 全呼出の70.6%がStep3（形式整形＝31音抽出のリトライ）に費やされており、構成比は8bよりむしろ微増している。モデルサイズを上げても「1回のStep3呼出あたりの成功率」が上がっただけで、「1つの句を確定させるまでに必要なStep3反復回数」自体は改善していない。
- **タイムアウト0回は明確な改善。** 8bでは180秒タイムアウトが5回発生していたが、14bでは0回。Ollama無応答ハングの頻度が減った可能性がある（n=10の観測のため確度は高くない）。

## 7. 未解決事項・次の一手（優先順）

7/30報告書の提案のうち、モデル切替では解決しなかった以下が引き続き優先候補である。

1. **Step3低成功率の構造的要因の検証**（8b報告 第8章・未検証事項2、Ollama不要・数分で完了）— `extract_mora_segment`が実在の古典和歌をどの程度通すかを測る。今回もStep3が全呼出の70.6%を占め、モデルサイズでは解決しないことが示されたため、優先度がさらに上がったと判断する。
2. `WakaPersona.best_match`の自己強化ループ対策・`gaze_path`丸写し対策（8b報告 第6章）— 本セッションでは診断していないため、14bでも同様の現象が起きているかは未確認。
3. Step1.5閾値（25/50音）の再設定。

### Phase Bへの判断

7/30報告書の「推奨しない」判断を維持する。A層到達率は改善したが29.0%はまだ低く、Phase B目的③（ShikimokuCheckerとの整合性確認）を100句規模で有意に検証できる水準ではない。またStep3の構造的低成功率が未解決のまま100句を走らせても、修正後に再走行が必要になる可能性が高い。
