## 1. 背景と目的（なぜこの作業をするのか）

### 1-1. 現状

S-2 の照合スクリプト `script/analyze_minase_label_correlation.rb`（読み取り専用、未コミット）を実行した結果、次のことが分かった。

- 手ラベル（近=1・中=2・遠=3、30ペア）と相関があったqwen3:8b の系列は、S-0b の `season_gap`（Spearman ρ=0.458）の1本だけだった。しかし、同じ軸で指示文だけを変えた S-0c では ρ=0.150 に落ち、再現しなかった。material と scene は全ペアが「3」の1値で、相関そのものが計算できない
- LLM を呼ばない bui 距離（部立の重なりから決定論で出す量）が ρ=0.411 で、手ラベルに沿って単調に増える。遠の9ペアはすべて bui 距離が 1.0 だった

### 1-2. 解釈に必要な、まだ足りない情報

この結果を「使える・使えない」の判断に使うには、次の3点を先に確かめる必要がある。

1. **恋→恋のペアの影響。** 恋は続けるのが式目の定めで、恋の続きは手ラベルで「近」になりやすく、bui 距離も 0.0 になりやすい。この少数のペアが、bui 距離と手ラベルの相関を実力以上に押し上げている疑いがある。除いた場合の相関を並べて見る
2. **系列が多いことによる偶然の混入。** 12本の系列を見ると、偶然でも1本が高く出る。S-0b の季軸のρ=0.458 が偶然の産物かどうかは、ラベルを並べ替えた場合の分布（置換検定）と比べて初めて判断できる。系列全体を見ているので、「最大の |ρ|」を基準にする多重比較の補正が必要
3. **今後の系列を同じ枠で測る受け口。** S-1（Jev）や、8b への3択実験（S-4）の結果を、同じスクリプトで手ラベルと突き合わせたい。系列を増やすたびにスクリプトを書き換えずに済む形にする

本依頼は、この3点を照合スクリプトに足す。**LLM は呼ばない。解釈や閾値の提案もしない**（数字を出すところまで）。

## 3. やること

### 3-1. 設計の提示（承認ゲート①）

下記 3-2 の各項目の実装方針（特に「恋→恋」の判定方法、多重比較の系列集合、置換検定の仕様）を提示して **一度停止**。Nobuson の明示的承認後に実装へ進む。

### 3-2. スクリプトの変更（`script/analyze_minase_label_correlation.rb`）

**(a) 浮動小数点の誤差による同順位の見落としを防ぐ**

系列（ペアごとの連続値）を作る時点で `round(9)` に揃える。`rank`・`kendall_tau_b`・「値の種類数」が、同じ同順位の扱いになるようにする。

**(b) 恋→恋のペアを除いた場合の相関を並べて出す**

- 原表の季欄で、**前句・付句がともに恋**のペアを「恋→恋」と定義する（判定の詳細は §0 の確認結果を見て承認ゲートで提示）
- 該当ペアの一覧（pair_no、前句の季欄、付句の季欄）を、標準出力に出す
- 表1（順位相関）と表2（手ラベル別の平均）を、**全30ペアの版**と**恋→恋を除いた版**の両方で出す。除いた版は n と、ラベルごとの件数も併記する

**(c) ラベルの並べ替え（置換検定）による確からしさの評価**

- 手ラベルを並べ替えて Spearman を再計算し、観測値がどの程度偶然に出るかを見る
- 回数 10000、乱数シード 20260930（`Random.new`）、ヘッダーに記録する
- 系列ごとに、**両側の p 値**（|ρ| が観測値以上になる割合）を出す
- **多重比較の補正**：各並べ替えで、系列全体の「最大の |ρ|」を記録し、観測された各系列の |ρ| が、その最大値の分布のなかでどの位置にあるか（補正済み p 値）も出す。この「系列全体」の集合には、**相関が計算できる 8b の系列（N/A でないもの）**を入れる。bui 距離は参考系列として、補正の対象に入れず、自分の p 値だけを出す
- p 値の下限は 1/(回数+1)。ヘッダーにも書く
- 全30ペアの版と、恋→恋を除いた版の両方で行う
- Kendall τ-b の p 値は不要（Spearman のみ）

**(d) 季移りと手ラベルの分割表**

原表の季欄で季移りの有無（S-0 のシート生成と同じ定義）を出し、季移りあり・なしと、手ラベル（近・中・遠）の30ペアでの分割表を出す。季軸の相関が、季移りの有無をそのまま拾っているだけかどうかを見る材料になる。

**(e) 追加系列を、スクリプトを書き換えずに受け取る**

- コマンドライン引数：`--extra NAME=PATH`（複数指定できる）
- 入力の形式：CSV。列は `pair_no,value`（ペア単位の連続値1つ）。`#` で始まる行は読み飛ばす（`skip_lines: /\A#/`）
- 30ペア以外の pair_no が入っていても無視し、30ペアのうち欠けているものがあれば異常終了する
- 追加系列は、表1〜3・(b)〜(c) の対象になる。多重比較の系列集合には**含める**（8b と同じ扱い。bui 距離だけが参考系列）

**(f) 出力の見出しに、次の注意を固定文言で入れる**

> 30ペアは折面・季移りで層別抽出したもので、無作為抽出ではない。この30ペアでの一致度であり、母集団の相関ではない。系列が多いので、補正前の p 値だけで判断しない。
