## §2 実装方針（D-33-1準拠：diff提示→承認→実装）

### 判定ロジック

「しも」という文字列を含む句に対して、以下の順序で判定する：

1. `morphemes_of(text)`で形態素列を取得（既存の`VerseTextAnalysis#morphemes_of`を使用）
2. 「しも」に対応する形態素を検索
3. **MeCabが直接「助詞-係助詞」と判定した場合** → 季語ではない（スキップ）
4. **MeCabが「名詞」と判定した場合** → 霜（季語）として扱う
5. **判定が曖昧な場合のフォールバック**（MeCabが古典語を正しく解析できない場合を考慮）：
   - 前の形態素の品詞が「動詞活用形・副詞・助詞」→ 係助詞（スキップ）
   - 文頭、または前の形態素が格助詞（の・に・を・が）→ 霜（季語）

### 実装上の注意点

- **事前検証必須**：IPA辞書のMeCabが「しも」を係助詞として正しく解析できるか、
  実際の古典和歌テキストで確認してから実装に進むこと
  （古典語に弱い場合はフォールバックロジックが主軸になる）
- **複合語は対象外**：「しもやけ」「しもつき」はMeCabで1形態素として解析されるため、
  「しも」単体に分解されず本修正の対象にならない（既に安全）
- **「しも」以外のSEASON_WORDS語彙は今回対象外**：
  Phase0調査で他の語の実害は確認されなかったため、今回は「しも」のみに限定する
- **`:direct`戦略・`RengasController`への影響がないこと**を確認する

### 修正対象

- `season_from_text`メソッド（または呼び出し元の季語判定箇所）
- 変更は最小限とし、「しも」の判定部分のみに局所化する
